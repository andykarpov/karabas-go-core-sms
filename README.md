# Sega Master System / Game Gear / SG-1000 core for Karabas Go / Mini / Mini G

Work in progress. A port of the [MiSTer SMS core](https://github.com/MiSTer-devel/SMS_MiSTer) to the Karabas Go board family (Xilinx Spartan-6 XC6SLX25), with the board glue of [karabas-go-modules](https://github.com/andykarpov/karabas-go-modules). The plan is in [docs/PLAN.md](docs/PLAN.md) (Russian).
